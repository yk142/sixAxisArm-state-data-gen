# 要件定義（叩き台）— 6 軸 Neural State Model 学習データ生成

状態: **一部決定**。決定済み: ①真値は Simscape/URDF、RNEA は残差型の解析モデル、②段階は腕 3 軸（J1〜J3）→ 6 軸（2026-10-11）。[handover.md](handover.md) §5 の 3〜7 は未決（Phase 0 の実測後に決める）。

## 目的
EPSON C8-A901S の 6 軸について、Neural State Model（次時刻状態予測）の学習データを生成し、学習・評価する。

## 機能要件（案）
| ID | 要件 |
|---|---|
| FR-1 | 真値プラント: C8-A901S の 6 軸（またはその部分集合）。8 kHz 固定ステップ。物理検証（重力トルク、自由落下、リミット到達、RNEA との一致）に合格 |
| FR-2 | シナリオ: 励振（BLN / chirp / step / micro）、姿勢保持（代表姿勢）、PTP ベンチマーク、リミット接触。シード固定で再現 |
| FR-3 | 1 kHz 変換: 状態は瞬時値の間引き、トルクは区間平均。遷移 `(x_k, τ_k) → x_{k+1}` |
| FR-4 | split: シナリオ単位の train / val / test / benchmark。正規化統計は train のみ |
| FR-5 | 検証関数: 有限性、トルク・速度・角度の範囲、解析モデルとの 1 ステップ整合、split リーク |
| FR-6 | カバレッジ評価: 時系列、位相平面（軸別）、周波数、PTP の包含率。6 軸向けに指標を再設計する |
| FR-7 | 他言語出力: HDF5（h5py から (N,d)、0 始まり ID） |
| FR-8 | 学習・評価（Python / PyTorch）: 1 ステップ誤差、短窓の開ループ、PTP 閉ループ。解析モデル＋残差 NN を基準に |

## 精度要件（追記: Phase 4-8、#63）
用途（ペイロード変化時のゲイン最適化、制振、位置決め精度の模擬）に対する定量要件は [phase4_8_accuracy_requirements.md](phase4_8_accuracy_requirements.md)。水準 G（ゲイン最適化: ΔOS ≤2 ポイント、Δ整定 ≤10%、最適ゲイン一致、ステップ区間位置誤差 ≤0.1°、ペイロード 0〜8 kg）と水準 P（位置決め: 先端 ≤0.03 mm = C8-A901S の繰り返し精度 ±0.03 mm）。

## NN の役割と速度要件（追記: #87、2026-10-31）
- NN の役割は**計算の高速化**。使い方は**逐次**（1 本ずつ）。
- 速度要件: **実時間より速いこと**（1 ms 分の計算を 1 ms 未満、この PC の CPU で計測）。主な比較は Simscape 真値、最適化した 2 慣性解析の速度も併記する。
- 精度要件: 水準 G（[phase4_8_accuracy_requirements.md](phase4_8_accuracy_requirements.md)）を弾性真値（#71）で満たす。Δ整定は「≤10% **かつ** ≤20 ms」で判定する（コードを要件に揃える）。最適ゲインの格子は ζ を 3 程度まで広げ、真値の最適が端に来ないことを確認する。
- 教師データ: Simscape に加え 2 慣性解析（真値と一致を確認済み）でも作ってよい。最終判定は Simscape 真値。
- 根拠: 弾性真値では 2 慣性解析が陰解法・8 サブステップを要し、逐次で重い。1 ms に 1 回の NN が速度で優位になり得る（剛体では最適化した解析に対する NN の優位は小さかった、#39・#41）。

## 目的の置き直し（追記: #91・#93、2026-10-31）
- 目的: 手先の繰り返し精度 ±0.02 mm が必要な場合に、**実時間より速く**（逐次、1 ms 分を 1 ms 未満）計算できる手法を探す。手法は解析・NN を問わない。
- 精度要件（水準 P02）: PTP の位置決め後（各到達点の 0.2 s 停留の終わり）の先端位置（フランジから 0.1 m 先）の、モデルと Simscape 真値（弾性）の差 ≤ 0.02 mm。評価は PTP 12 本（速度 0.2/0.4/0.6/0.8 × 3 本、ペイロード 0 kg、既定ゲイン wn 60・ζ 1）。真値自体の数値誤差がこれより十分小さいことを確認する。
- 水準 G の整定時間は「絶対 ≤ 20 ms」のみで判定する（#93。相対 10% は整定の短いケースで過敏）。
