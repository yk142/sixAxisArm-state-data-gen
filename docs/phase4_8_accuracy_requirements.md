# Phase 4-8: 精度要件の定量化（叩き台）（#63）

状態: **確定（2026-10-18、ユーザー確認済み）**。残る未確定は下の「未確定・次の判断」のみ。

## 用途
1. 手先ペイロードが変わったときの制御ゲイン最適化（NSM でゲイン候補を多数試す）
2. 制振性の評価（弾性は未実装。別段階）
3. ロボット位置決め精度の模擬

用途 1 と 3 では要求精度が桁違いに違うため、2 つの水準に分ける。

## 換算: 関節角誤差 → 先端位置誤差
運動学（`c8_params` の関節配置、先端 = arm6 フレーム z 方向 0.1 m）で、可動範囲の 80% 内のランダム姿勢 2000 点を評価した。
- 6 軸すべてが最悪の向きに同時にずれた場合: **0.01° ≈ 0.23 mm**（中央値。95% 点 0.28 mm、最大 0.31 mm）
- つまり 0.1° ≈ 2.3 mm（最悪側。1 軸だけなら小さい）。以前の概算 0.1° ≈ 1.6 mm は到達距離 0.9 m の単軸の値で、最悪側ではこちらの方が大きい。

## 実機仕様（確認結果）
EPSON C8 シリーズの公開仕様（[Epson C8](https://www.epson.com.sg/p/C8)、[encycam: C8-A901S](https://encycam.com/component-library/epson-c8-a901s)）:
- 定格ペイロード 3 kg、最大ペイロード 8 kg（アーム長 901 mm）
- 繰り返し位置決め精度: シリーズの表記は ±0.02 / ±0.03 / ±0.05 mm（アーム長 711 / 901 / 1400 mm の順と読める）。C8-A901S は **±0.03 mm** と読めるが、型番ごとの対応は公式データシートで未確認。**水準 P は C8-A901S をベースに ±0.03 mm で考える（ユーザー決定）。**
- ペイロード範囲は **0〜8 kg**（最大ペイロードまで。評価済みの掃引と同じ）。定格 3 kg 以下は主に使う範囲。

## 要件

### 水準 G: ゲイン最適化に使えること（用途 1）
（数値はユーザー確認済みの案。ペイロード範囲 0〜8 kg。最適ゲイン一致は、最適 wn が掃引の端に張り付く間は弱い基準で、弾性・遅れを入れた段階で再評価する。）
目的は「真値と同じ最適ゲインを選べる」こと。次を提案する。
| 指標（Simscape 真値との差） | 許容（★） | 根拠 |
|---|---|---|
| オーバーシュートの差 | ≤ 2 ポイント | 制振要求の 5% 基準に対し 40% 以内 |
| 整定時間の差 | ≤ 10%（かつ最大 ≤ 20 ms） | ゲイン格子の刻みで整定が変わる量より小さい |
| 最適ゲイン（OS≤5% で整定最小）の選択 | 全ペイロードで真値と一致 | 選択を誤ると最適化の意味がない |
| 位置誤差（ステップ区間） | ≤ 0.1° | 先端で最大 ≈ 2.3 mm 以内 |

### 水準 P: 位置決め精度の模擬（用途 3）
| 指標 | 許容（★） | 根拠 |
|---|---|---|
| 位置決め後の先端誤差 | **≤ 0.03 mm（C8-A901S の繰り返し精度。最悪側換算で関節 ≈ 0.0013°）**。参考: 0.1 mm は関節 ≈ 0.004° | 実機仕様をそのまま狙いとし、厳しいことは承知のうえで実力を測る |
| 同上、重ね合わせ時系列 | 精度の下限が実機ばらつき以下 | |

## 現状の到達度
| モデル | 水準 G | 水準 P |

## シミュレーション条件（アーム長）との整合
シミュレーションの運動学は C8-A901S と整合している。確認方法: `c8_params` の関節配置から、可動範囲内のランダム姿勢 2 万点で J1 軸から手首中心（J5 原点）までの水平距離の最大を測ると **0.901 m**（= 仕様のアーム長 901 mm、J1 軸〜J5 軸中心の定義）。
- フランジ（J6 原点）で 0.98 m、先端 0.1 m 先で 1.08 m まで届く（アーム長の定義より先にフランジ・ツール分がある）。
- 先端位置誤差の換算は、先端 = arm6 フレーム z 方向 0.1 m として行った。ツール長が変われば換算（0.01° ≈ 0.23 mm）も変わる。ペイロードは arm6 の [0 0 0.05] m に置いている。
- 質量・慣性は URDF 由来で、実機との一致は未確認（真値と解析が同じ式のため、実機との差はこの評価に含まれない）。
- 繰り返し精度は定格条件（定格 3 kg 以下）での実機の再現性で、モデル誤差の許容とは別物。ここでは「モデルの先端誤差が実機のばらつき以内か」を水準 P の目安としている。

## 判断・含意
- ペイロードを知らないモデルは水準 G を満たさない。次段階（ペイロード入力付き A/B 再学習）の目標は、**水準 G を全ペイロードで満たすこと**とする。
- A は 0 kg でも水準 G の OS 差を満たさない（3.4 ポイント）。水準 P は解析のみが満たす。位置決め精度の模擬には、現状のニューラルモデルでは足りない（残差型の B は解析に近いので可）。
- 水準 P は ±0.03 mm とした。公式データシートでの確認は残る。

## 未確定・次の判断
1. 用途 3（位置決め精度の模擬）を要件に含める方針。A の改善（現状 0.02〜0.06°）を検討し、水準 P に届かない場合は B/解析を主軸にするかをそこで判断する（ユーザー判断）。
2. 水準 P の先端誤差の見積もりは最悪側（6 軸が最悪の向きに同時にずれる）。厳しすぎる場合は RSS 等に見直す。
3. C8-A901S の繰り返し精度（±0.03 か）を公式データシートで確認する。
