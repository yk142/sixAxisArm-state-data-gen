# Phase 4-3 報告（短い窓の開ループ評価と切替方式）（issue #37）

## 方法
- 窓: 同一シナリオ内で連続する L 遷移（L = 50, 200 ステップ = 50, 200 ms、窓の間隔 L/2）。test（L=50: 7,185 本、L=200: 1,770 本）と benchmark の PTP（4,274 / 1,053 本）。窓内に at_limit が 1 遷移でもあれば「接触を含む」、無ければ「自由運動」。
- 各窓の先頭の実測状態から、**実測のトルク列**を入れて L ステップ予測し、真の状態列と比べる（全長の開ループ再生はしない）。誤差は窓の終端と経路全体の RMSE（軸別）。
- 予測器: 状態維持 / 解析（RK4）/ hybrid（開始状態がリミット拘束中なら状態維持、他は解析。接触は状態維持とする 4-2 の方針）/ 4-2 本番の A・B・C（各 3 シード、再学習なし）。
- 実装: `python/sa_nsm/rollout.py`、`python/eval_window.py`、`python/summarize_window.py`。全表: `reports/issue-37/window_tables.md`、図: `reports/issue-37/window_error_curves.png`。

## 結果（終端の速度誤差 RMSE [rad/s]、J1/J2/J3、L=200）
| 区分 | 状態維持 | 解析 | hybrid | A | B | C |
|---|---|---|---|---|---|---|
| test 自由運動（1,529 本） | 0.91 / 0.94 / 1.39 | 1.3e-4 / 1.1e-4 / 1.9e-4 | 同左 | 0.32 / 0.46 / 0.71 | 0.077 / 0.10 / 0.18 | 2.1e-4 / 1.5e-4 / 2.8e-4 |
| test 接触を含む（241 本） | 0.56 / 1.22 / 1.77 | 2.11 / 2.19 / 5.15 | 0.57 / 1.25 / 1.89 | 0.65 / 0.95 / 1.39 | 0.22 / 0.58 / 0.80 | 2.11 / 2.19 / 5.15 |
| benchmark PTP（1,053 本） | 0.55 / 0.44 / 0.69 | 2.3e-5 / 1.9e-5 / 3.4e-5 | 同左 | 0.57 / 0.44 / 0.67 | 0.13 / 0.13 / 0.14 | 3.4e-4 / 1.3e-4 / 3.4e-4 |

（A・B・C は 3 シード平均。ばらつきは全表を参照。B は接触を含む窓の J1 で 0.22 ± 0.07 と大きい。L=50 でも同じ傾向。）

## 所見
1. **自由運動と PTP の窓では、解析モデルが圧倒的に正確**。200 ms 後の速度誤差は 1e-4 rad/s 台で、A・B は 3 桁以上大きい（B でも 0.08〜0.18 rad/s）。C は解析モデルとほぼ同じ（わずかに悪化: 2.1e-4 対 1.3e-4）。**自由運動で学習モデルが解析モデルに勝つ場面はない**。
2. **接触を含む窓では、解析モデルは状態維持より悪い**（拘束を知らない: 2.11 対 0.56 rad/s）。hybrid は状態維持と同水準で、これが接触の公平な基準線。
3. **B は接触を含む窓で hybrid より小さい速度誤差**（L=200: 0.22/0.58/0.80 対 0.57/1.25/1.89、約 2.2〜2.6 倍小さい）。ただし位置誤差は J1 で hybrid（0.014）より大きい（0.054）、J2/J3 は小さい（0.067/0.068 対 0.119/0.100）で、一様な改善ではない。A も hybrid よりやや小さい（0.65/0.95/1.39）。シード間のばらつきが大きく（B の J1 は ±0.07）、標準偏差を超える差は J2/J3 に限られる。接触窓は test で 241 本（L=200）と少ない。
4. ただし B は自由運動の窓では最悪級（A に次ぐ）で、B 単独は使えない。「接触に近いときだけ B を使う」切替の方式が、学習モデルが勝つ余地として残る（未評価）。

## 切替方式の評価（リミットから d 以内なら NN、他は解析）
- 方式: 各ステップで、いずれかの軸がリミットから d 以内（d = 0.5, 1, 2, 5°）なら NN（A または B）、そうでなければ解析モデル。ロールアウト中の予測状態で判定するので、窓の区分（接触を含むか）は使わない（実運用と同じ判定）。窓・指標は前節と同じ。実装 `python/eval_switch.py`、集計 `python/summarize_switch.py`、全表 `reports/issue-37/switch_tables.md`、図 `reports/issue-37/switch_contact.png`。
- NN を使うステップの割合は 9〜20%（d = 0.5° で B は約 9%）。

### 結果（test、終端の速度誤差 RMSE [rad/s]、J1/J2/J3、B は 3 シード平均）
| 窓 | 方式 | 自由運動 | 接触を含む | 全窓の合算 |
|---|---|---|---|---|
| L=200（1,529 + 241 本） | hybrid | 1.3e-4 / 1.1e-4 / 1.9e-4 | 0.57 / 1.25 / 1.89 | 0.21 / 0.46 / 0.70 |
| | B 切替 0.5° | 1.3e-4 / 1.1e-4 / 4.8e-4 | 0.23 / 0.54 / 0.75 | 0.089 / 0.20 / 0.28 |
| | B 切替 5° | 0.021 / 0.047 / 0.088 | 0.24 / 0.56 / 0.77 | 0.094 / 0.21 / 0.31 |
| L=50（6,370 + 815 本） | hybrid | 1.1e-4 / 7.9e-5 / 1.6e-4 | 0.45 / 0.80 / 1.06 | 0.15 / 0.27 / 0.36 |
| | B 切替 0.5° | 0.012 / 0.024 / 0.015 | 0.32 / 0.46 / 0.55 | 0.11 / 0.16 / 0.19 |
| | B 切替 5° | 0.046 / 0.058 / 0.065 | 0.52 / 0.49 / 0.53 | 0.22 / 0.17 / 0.19 |

PTP（benchmark）は切替幅によらず解析モデルと完全に同じ（リミット近傍に入らない）。A の切替は接触窓の改善が小さい（L=200 で 0.67 / 0.96 / 1.39）。

### 所見
1. **B の切替（d = 0.5°）は、接触を含む窓で hybrid より速度誤差が小さい**: L=200 で 2.4 / 2.3 / 2.5 倍（0.23 / 0.54 / 0.75 対 0.57 / 1.25 / 1.89）、L=50 で 1.4 / 1.7 / 1.9 倍。全窓の合算でも L=200 で約 2.3〜2.5 倍、L=50 で 1.3〜1.9 倍小さい。基準線は hybrid（解析モデルや状態維持より強い）なので、弱い基準線に対する倍率ではない。
2. **代償**: 自由運動でも、リミット近傍の窓は B を通るため、L=50 では 1e-4 → 1e-2 rad/s 台（約 100 倍）に悪化する。絶対値は接触窓の誤差（0.3〜1 rad/s）より 1〜2 桁小さく、合算では差し引きで改善するが、近傍の自由運動の精度を落とす。切替幅を狭めるほど代償が小さく（d = 0.5° が最良）、広げると改善が消える（d = 5° でほぼ同等か悪化）。
3. **位置誤差は一様に改善するわけではない**: L=200 の接触窓で、J2/J3 は小さい（0.061 / 0.066 対 0.119 / 0.100）が、J1 は大きい（0.0235 対 0.0143）。
4. 速度誤差の改善は、B のシード間のばらつき（L=200 の J1 で ±0.06 程度）より大きい。ただし接触窓は test で 241 本（L=200）と少なく、シナリオ単位の独立性が低い。d の選択は同じ test の窓で比べているので、d = 0.5° を選んだ分は楽観的に見えている可能性がある（val で選び直していない）。

### 留意点
- 評価はまだ開ループ（実測トルク列）の短い窓。閉ループでの挙動は未評価。
- B の接触予測は 4-2 の本番モデル（改良前）。改良版 C（v6/v7）は未保存で未評価。
- 閉ループ PTP 評価（制御器の Python 移植）は、PTP がリミット近傍に入らず解析モデルと同じになるため、学習モデルの優位は見込めない（PTP では切替方式 = 解析モデル）。見送りとし、必要になれば再検討する。
