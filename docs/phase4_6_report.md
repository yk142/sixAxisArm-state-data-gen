# Phase 4-6: 6 軸の A の改善（ハイパーパラメータ探索と 3 seed）(#57)

## 目的
4-4（#53）・4-5（#55）で、6 軸の A（純 MLP）は解析より 1 ステップ RMSE で約 25〜210 倍悪く、閉ループでも手首軸・高速 PTP で誤差が大きかった。A は 3 軸の設定（幅 512・深さ 4・60 エポック、seed 0）のままだった。6 軸向けに調整して、誤差がどこまで下がるかを確かめる。

## 方法
- 共通: 4-3d の A（加速度表現、非接触の行のみ学習、Adam・lr 2e-3・バッチ 4096、モデル選択は val の自由運動の加速度 RMSE）。変えたのは幅・深さ・エポック数・ドロップアウト・重み減衰。
- 探索は seed 0 のみ。最良の設定（幅 512・深さ 4・重み減衰 0.2・100 エポック）で seed 0〜2 を学習し、窓評価（4-4 と同じ）と閉ループ評価（4-5 と同じ 40 本）を行った。
- 結果: `reports/issue-57/summary.md`、`tune.png`。

## 結果
### 探索（seed 0、val 自由運動の加速度 RMSE の軸平均）
| 設定 | val 平均 |
|---|---|
| 元（幅 512・深さ 4・60 エポック） | 2.52 |
| 深さ 6・40 エポック | 2.51 |
| 100 エポック | 2.43 |
| ドロップアウト 0.1 | 3.16（悪化） |
| 重み減衰 0.05 / 0.2 / 0.5 | 1.79 / 1.53 / 1.91 |
| 重み減衰 0.2・幅 1024（60 エポック） | 1.30 |
| 重み減衰 0.2・100 エポック | 1.22 |

- 容量（深さ）・エポック数だけでは改善しない（2.5 付近）。学習損失は 1e-4 まで下がるが val は約 100 倍（標準化した二乗誤差）で、汎化がボトルネック。
- 重み減衰が効く（0.2 が最良、0.5 は強すぎ）。重み減衰を入れたうえでは、エポック数・幅を増やすと改善が続く（探索はここで打ち切り。200 エポック・幅 1024 で 100 エポックなどは未実施）。

### 調整後 A（3 seed）と調整前・解析・B
1 ステップ加速度 RMSE（test、自由、[rad/s²]、J1〜J6）:

| モデル | RMSE |
|---|---|
| 解析 | 0.0109 / 0.0052 / 0.0115 / 0.074 / 0.120 / 0.181 |
| B | 0.0107 / 0.0052 / 0.0113 / 0.069 / 0.093 / 0.081 |
| A 調整前 | 2.25 / 0.90 / 1.77 / 3.27 / 3.13 / 4.47 |
| A 調整後（3 seed 平均） | 1.35 / 0.42 / 0.89 / 1.88 / 1.97 / 0.99 |

- 調整前に対し 0.22〜0.63 倍（J6 が最大の改善）。seed 間のばらつきは小さい（J1〜J6 とも 3 seed の範囲は平均の ±10% 程度）。
- 解析との差は約 5〜125 倍（J1 約 125、J6 約 5.5）で、調整しても解析の精度には届かない。

自由窓 L=200 の終端速度誤差（[rad/s]）: 調整前 0.11〜0.20 → 調整後 0.03〜0.13（解析は 6e-5〜1e-3）。

閉ループ（位置 RMS の軸別最大、[deg]）:
- PTP 12 本: 調整前 0.033〜0.129 → 調整後 0.020〜0.060。手首（J5・J6）で大きく改善（0.13→0.04、0.13→0.03）。J2・J3 はほぼ変わらない。解析は 4e-5〜1e-4、B は 6e-5〜8e-4。
- 保持（nearlimit）28 本: 調整前 0.0014〜0.0104 → 調整後 0.0016〜0.0092。J1〜J5 では同等かやや悪い（J2・J3 は seed によっては調整前の約 1.5〜2 倍）で、J6 だけ改善。リミット近傍では改善が確認できない。
- 発散は 0 件（調整後 3 seed × 40 本）。

速度: アーキテクチャは調整前と同じ（幅 512・深さ 4）なので、1 ステップの速度は変わらない（4-4 の測定: バッチ 1 で 0.77 ms、解析サブステップ 1 は 1.21 ms）。

## 結論
- 6 軸の A は、重み減衰（0.2）と学習の延長（100 エポック）で、1 ステップ誤差が約 1/2〜1/5 になった。閉ループ PTP の誤差も手首で約 1/3〜1/4 になった。
- それでも解析（誤差 1e-4 台）には届かず、1 ステップ RMSE で約 5〜125 倍悪い。A の速度優位（解析サブステップ 1 に対し約 1.6 倍）と釣り合うほどの精度ではない。
- リミット近傍保持では改善が見られない（学習が非接触・非リミット行のみのため、リミット付近の入力は分布の外にある可能性。未検証）。

## 留意点
- 探索は seed 0 のみで、設定の優劣の差（例: 幅 1024 と 100 エポック）は seed 間のばらつきの範囲内かもしれない。最良設定の 3 seed の val 平均は 1.22 / 1.11 / 1.21。
- 探索は網羅的でない（学習率、バッチ、活性化、入力特徴、データ量などは未探索）。エポック数・幅は伸ばすと改善が続いており、打ち切りの設定が最適とは限らない。
- 重み減衰が汎化を改善した理由は検証していない（過学習の抑制と推測）。
- 解析と真値は同じ式なので、解析との差は実機との差ではない。接触は評価していない。
