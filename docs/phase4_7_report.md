# Phase 4-7: 手先ペイロード変化の閉ループ評価（剛体、制御ゲイン掃引）（#61）

## 目的
手先の重りが変わったときの制御ゲイン最適化に NSM が使えるか。弾性なし（剛体のみ）で、ペイロード 0/1/3/5/8 kg × PD ゲインの閉ループステップ応答を、Simscape 真値と各モデルで比較する。

## 設定
- ペイロード: arm6 座標系 [0 0 0.05] m の点質量を link6 に合成（`saApplyPayload`、平行軸定理）。Simscape は URDF 由来のパラメータ構造体 `p` を書き換え、解析側は同じ値を JSON で渡す。
- シナリオ: 姿勢 P0 で静止 → t=0.6 s に 1 軸だけ 2° ステップ（6 軸それぞれ）。FF はペイロード込みの RNEA（重力たわみを除き、ゲインの効果を見る）。
- ゲイン: Kp = Mmean·wn²、Kd = 2ζ·Mmean·wn（公称 Mmean）、wn = 30/60/100/150、ζ = 0.5/1/2。計 5×12×6 = 360 本（Simscape 3169 s）。
- 指標: オーバーシュート（目標に対する %）、2% 整定時間。最適ゲイン = オーバーシュート最大 ≤ 5% の中で整定時間（軸平均）が最小。
- 比較モデル: 解析（ペイロード反映／公称）、A（調整後 wd0.2・e100・s0）、B。A・B は公称ペイロードで学習済み（ペイロード入力なし）。

## 結果（詳細は `reports/issue-61/summary.md`）
1. ペイロード反映の解析は真値と一致（位置誤差 最大 2.5e-2°、オーバーシュート差 0.17%、整定差 1 ms）。
2. ペイロードを知らないモデル（解析公称・A・B）は、ペイロード 1/3/5/8 kg で真値から最大 1.0/3.1/5.3/8.8° ずれる。3 者の差はほぼ無い（ペイロード入力が無いため）。A・B 固有の劣化ではない。
3. 真値でのペイロード依存: wn≥100・ζ=1 でオーバーシュートが 0 → 2.4%（wn=100）/3.1%（wn=150）と 8 kg まで増える。ζ=2 は常に 0。ζ=0.5 は 4〜11%（ペイロードで増加）。整定時間はペイロードで ±10〜40% 程度変わり、ζ=0.5 と 1 の優劣が wn=60 では 3〜4 kg で入れ替わる。
4. 最適ゲイン（OS≤5%）: 0/1/3 kg は wn=150・ζ=1、5/8 kg は wn=150・ζ=2。ペイロード反映の解析は 5/5 一致、公称・A・B は 3/5（5/8 kg の ζ 切替を外す）。

## 限界
- 最適 wn は掃引範囲の端（150）。剛体・遅れなしでは高ゲインほど有利になるだけで、実機の制約（サンプル遅れ、弾性、トルク飽和）が入って初めて意味のある最適値が出る。ここでの「最適ゲイン一致」は手法の感度確認であり、実機の最適値ではない。
- 真値と解析は同じ式のため、解析≈真値は実機の話ではない。
- 制振（弾性）は未評価。弾性は Simscape 真値の拡張が必要で別段階。
- 精度要件（許容誤差 %）は未定義。

## 次の段階の候補
ペイロード入力を加えた A/B の再学習、弾性の追加（制振）、実機側の遅れ・パラメータ誤差を入れた真値、要件の定量化。
