# Phase 4-3h: C(4-2) の閉ループ接触評価（issue #51）

Phase 4-3f（#47）と同じ接触押し付け 12 本（`data/export/closed_contact3.h5`、真値は再利用）で、C(4-2) の 3 seed（`data/models/full3/C_s{0,1,2}`、新規学習なし）をプラントにした閉ループを評価した。実行は `python/eval_closed.py --only-c --hold-name contact`、集計は `python/summarize_contact.py data/eval/closed_contact3 reports/issue-51 data/eval/closed_contact3_c`。指標の定義は 4-3f と同じ。表は `reports/issue-51/summary.md`、図は `reports/issue-51/contact_closed_loop.png`。

- **C(4-2) は 3 seed とも解析と同じ結果。** リミット超過は中央値 4.29〜4.30°、最大 6.88°、位置 RMS 最大 4.08°（解析と 3 桁まで一致）。壁を通り抜ける。seed 間の差はない。
- B で見えた壁の前倒しと J2 への漏れ込みは C にはない（他軸の最大誤差 0.12°、12 本とも `ok`）。ただし接触を保てているわけではなく、解析と同じ「何も起きない」挙動によるもの。
- 全モデルで数値の破綻（NaN・|q|>10 rad）はなし。

## 原因（確認）
- C の接触ヘッドが出力していない。J3 下限・トルク −381 N·m・速度 0 の 1 ステップ加速度は、C = −401.1、解析 = −400.7 rad/s²（距離 2° 〜 −2°）。ゲートは 0.5° で 0.5、0° で 0.92 と開いている。
- 学習データの at_limit 行（J3 下限・外向きトルク −100 以下、2000 行）でも、真値の加速度は平均 +4.6 に対し、C は −95.0、解析は −94.9。**C は学習データ上の接触すら再現していない。**
- これは Phase 4-2 の既知の問題と一致する（`docs/phase4_2_report.md`: 「C の接触誤差は解析モデルの値と小数 3〜4 桁まで一致」。val 損失が 2〜10 エポックで最小になる過学習のため、学習初期のモデルが選ばれ、接触ヘッドが出力していない）。今回の閉ループ評価でも同じ結果になった。

## 制約
- 4-2 の C は、接触ヘッドが事実上未学習のモデル。「接触を学習した C」の評価にはなっていない。
- 真値は 4-3f と同じ（接触は Simscape のバリア）。評価は 12 本。
