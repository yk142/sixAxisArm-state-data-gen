## 基準線の 1 ステップ誤差（加速度換算 RMSE [rad/s²]、J1 / J2 / J3、小さいほど良い）
解析モデル = RNEA＋摩擦、データのトルク（区間の台形平均）を 1 ステップ一定として RK4。「解析＋ストッパ」= 可動範囲の端で位置を止め外向き速度を 0 にする単純な非弾性ストッパ付き。「目標の RMS」は真の Δdq/Δt 自体の大きさ（誤差の相場感）。

**test**（180,500 遷移）
| 区分 | 遷移数 | 目標の RMS | 解析モデル | 解析＋ストッパ | 状態を変えない |
|---|---|---|---|---|---|
| 全体 | 180,500 | 17.3 / 21.5 / 41.6 | 11.2 / 16.4 / 37.8 | 25.2 / 35.3 / 37.0 | 17.3 / 21.5 / 41.6 |
| 非接触 | 162,269 | 14.8 / 15.5 / 23.1 | **0.0105 / 0.0064 / 0.0122** | 同左 | 14.8 / 15.5 / 23.1 |
| 接触 | 18,231 | 31.5 / 49.3 / 111 | 35.2 / 51.5 / 119 | 79.3 / 111 / 117 | **31.5 / 49.3 / 111** |
| 　動的な接触 | 4,561 | 63 / 98.6 / 222 | 65.9 / 101 / 233 | 159 / 222 / 232 | **63 / 98.6 / 222** |
| 　静止押し付け | 13,670 | 0.145 / 0.173 / 0.177 | 14.3 / 12.1 / 27.4 | 0.85 / 1.01 / 8.67 | **0.145 / 0.173 / 0.177** |

**PTP ベンチマーク**（107,294 遷移、非接触）: 目標の RMS 3.04 / 2.58 / 4.35、解析モデル **0.0012 / 0.0008 / 0.0022**、状態を変えない 3.04 / 2.58 / 4.35。

val も同じ傾向（`reports/issue-33/baseline.md` にパターン別の全表）。

## 所見
1. **非接触の遷移では、解析モデルがほぼ完全**（目標の RMS の 0.05〜0.1%、PTP は 0.04〜0.05%）。学習で上積みできる余地は、この領域では極めて小さい。**NN の残差は 10⁻² rad/s² 台の小さな量を学ぶことになる**ので、損失の標準化と、評価の指標（誤差の絶対値と、閉ループでの積み重なり）が 4-2 の設計の要になる
2. **接触では、解析モデルは何の予測力も持たない**。動的な接触の誤差は目標の RMS とほぼ同じ（65.9 対 63 など）。非弾性ストッパを付けるとかえって悪化する（159 対 63）。静止押し付けでは「状態を変えない」が最良（0.145）で、解析モデルは 14〜27、ストッパ付きも 0.85〜8.7 と悪い。**接触の基準線は「状態を変えない」**とし、学習モデルとの比較ではこの値を用いる（弱い基準線との倍率は主張しない）
3. 全体の誤差は接触が支配する（test 全体で解析モデル 11〜38。非接触 0.01）。**全体の 1 つの数字では評価せず、非接触・動的接触・静止押し付けを分けて見る**（J2 版の教訓と同じ）
4. 3-3 で報告した解析整合の残差比（非接触 1〜4%）と値が違うのは、指標の違い。3-3 は「区間の先頭の瞬時加速度」と比べ、ここでは「区間の平均トルクで積分した Δdq」と比べている。後者のほうが、データの定義（台形平均）に合っている

## 限界・未実施
- 学習は含まない（4-2）。学習済みモデルとの比較表は 4-2 で埋める
- 「非接触」の区分には、接触シナリオ内で接触フラグの付かない遷移（接触の前後）が含まれる
- 動的な接触の判定は遷移単位（いずれかの軸が |dq| > 0.02 または |Δdq| > 0.005）で、3-5 の軸別の定義とは件数が違う
- train での基準線の誤差は未算出（学習時の標準化に使う残差の標準偏差は 4-2 で算出する）
- 6 軸のデータでの基準線評価は 4-4
