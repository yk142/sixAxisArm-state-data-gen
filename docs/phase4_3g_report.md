# Phase 4-3g: B(4-2) が接触押し付けで J2 を外した原因の調査（issue #49）

Phase 4-3f（#47）で、B(4-2) をプラントにした閉ループの `cp_nearlimit_j3m_002`（J3 下限へ 5° 押し付け）だけ、押し付けた J3 ではなく J2 が真値から最大 62° 外れた。原因を調べた。再現・探索は `python/diag_b_contact.py`、出力は `reports/issue-49/diag.txt`。モデルの修正は含めない。

## 経過（B の閉ループを再現）
- 1500〜1700 ステップ付近で J3 が下限 −61° に近づく。真値は −61° で止まるが、B は J3 を −55° 付近（下限の約 6° 手前）で止める。
- その間 PD は飽和し続け（J2 = +860、J3 = −381 N·m = tauPeak）、J2 は 1700 ステップ付近から一方向に流れて 6000 ステップで真値から −62°。
- 最後の 1.5 s の目標軸位置（真値はリミットの 0.04〜0.11° 内側）: J1・J2 の押し付け 8 本では B はリミットを 0.5〜3.6° 超え（壁を通り抜ける）、他軸のずれは 0.8° 以下。J3 の 4 本では B は J3 をリミットの 1.6〜4.7° 手前で止め、他軸の最大ずれは 0.13 / 0.33 / 6.9° / 62°（本件）。

## 原因（探索の結果）
学習データでは、真値と解析の加速度の差（接触の力）はリミットから 0.1° 以内の行だけに現れ、0.1〜20° の範囲は 0（J3 下限、train 全行）。つまり B の残差は本来 0.1° 以内でしか働かないはずだが、実際は次のようになっていた。

1. **J3 の壁が約 10° 手前から効く。** J3 トルク −381 のとき、J3 加速度は解析 −400 に対し、B は 10° で −119、6° で +189、2° で +468、0.1° で +586 と、距離とともに滑らかに壁へ向かって反発する（真値は 0.1° までほぼ解析どおり）。トルク −20 でも 1° 以内で符号が反転する。反発の大きさは学習データの平均（0.1° 以内で +58〜79）を大きく超える（+586）。→ J3 が下限の約 4〜6° 手前で釣り合って止まる。
2. **J2 に漏れ込む。** J3 を下限付近で飽和トルクにすると、B の J2 加速度は J2 トルク 0 のとき −94（20° 手前）〜 −209（0.1°）で、解析は ≈ 0。J2 トルクを +860（飽和）にしても −63〜+52 で、解析（+201）をほとんど打ち消す。→ PD が J2 を戻せず、J2 が一方向に流れる。

この 2 点が重なったのが本件。J1・J2 の押し付けでは壁の前倒し（手前で止まる）は起きず、逆に通り抜けており、J3 とは挙動が違う（理由は未調査）。

## 未確認・制約

- 学習は 1 seed（B_s0）。他 seed で同じ傾向かは未確認。
- 探索は速度 0・J1 = 0・J2 = −29° の 1 姿勢。
- J3 以外の軸で壁の前倒しが小さい理由は未調査。
