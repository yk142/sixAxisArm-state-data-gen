## 3. カバレッジ・解析整合（図: `reports/issue-31/`）
**軸別 q-dq 平面（40×40）**: train が占めるセル J1〜J6 = 59 / 56 / 64 / 62 / 61 / 59%。benchmark の被覆は 97.8〜100%（最小は J6 の 97.8%）。

**正規化 12 次元（q/半可動幅, dq/qdMax）の格子被覆**（train に同じセルの点が 1 点以上ある評価点の割合）
| 分割 | セル数 | val | test | benchmark（PTP） |
|---|---|---|---|---|
| 4 | 1.7×10^7 | 45.9% | 36.2% | 8.1% |
| 6 | 2.2×10^9 | 39.4% | 31.5% | 0.5% |
| 8 | 6.9×10^10 | 34.5% | 29.2% | **0.0%** |

- 3 軸（6 次元）の 8 分割は val 66〜71%、PTP 14%。次元が倍になり、**val・test でも 3 割台、PTP は 8 分割でゼロ**。train が占める 8 分割のセルは 28,850（全体の 4×10^-7）。12 次元の格子被覆は、この規模のデータでは PTP の比較に使えるほどの解像度がない（0% では改善も測れない）。軸別の平面と、6 次元以下の部分空間（軸ごとの組）での評価を併用する必要がある
- 速度範囲: train の |dq|/qdMax の 99.9 パーセンタイルは 0.79 / 0.64 / 0.73 / 0.63 / 0.62 / 0.62、最大 0.80 / 0.81 / 0.79 / 0.79 / 0.79 / 0.78。benchmark がこれを超える点は J1〜J6 で 0.23 / 0.15 / 0.34 / 0.88 / 0 / 2.32%（手首、特に J6 で PTP が train の速度範囲を超える）
- 解析整合（パターン別の残差 RMS / 加速度 RMS）: 手首 J4〜J6 は励振で 2〜10%、**hold（姿勢保持）と nearlimit で 21〜31%**。J1〜J3 は 3 軸と同程度（0.5〜11%）。hold での手首の比が大きい原因は未調査（加速度がほぼゼロの区間で比の分母が小さいことが一因の可能性）
