# Phase 4-3d: NN A（純 MLP）の自由運動精度の改善（issue #42）

## 目的
接触なし前提で、NN A（解析モデルを使わない MLP）の精度を、解析のサブステップ 1 並み（1 ステップ加速度誤差 約 0.02 rad/s²）にどこまで近づけられるかを測る（達成の可否は問わない）。

## 方法（`python/train_a.py`、`python/eval_a_window.py`）
- データ・入力は 4-2 と同じ（3 軸 full、X_spec 12 列）。モデルは val の自由運動の加速度誤差で選び、test は最後に報告する。
- 変えた点:
  1. 出力の表現: 標準化した Δ（4-2 と同じ）に対し、`[(Δq − dq·dt)/dt², Δdq/dt]`（加速度の単位、非接触の分散で標準化）。解析モデルは使わない。
  2. 学習行: 全データ / 非接触（at_limit でない遷移）のみ。
  3. 幅・深さ・エポック・weight decay。
- 評価: 1 ステップ加速度 RMSE（test 非接触）と、自由窓（test、窓内に at_limit なし、L=50/200、開ループ、終端誤差）。

## 結果（test、非接触、1 ステップ加速度 RMSE [rad/s²]、3 軸平均）
| モデル | 平均 | J1/J2/J3 |
|---|---|---|
| 4-2 の A | 7.24 | 5.10/6.57/10.06 |
| r0 標準化出力・全データ（4-2 条件の再現） | 7.68 | 5.81/6.19/11.05 |
| r1 加速度出力・全データ | 7.55 | 6.08/5.85/10.72 |
| r2 加速度出力・非接触のみ（幅 256、20 エポック） | 1.27 | 1.25/0.94/1.62 |
| r4 同・40 エポック | 0.98 | 1.07/0.59/1.28 |
| r5 同・weight decay 0.05 | 1.25 | 1.25/0.93/1.58 |
| r3 幅 512・深さ 4、20 エポック | 0.86 | 1.11/0.48/0.99 |
| **r6 幅 512・深さ 4、60 エポック** | **0.72** | 0.94/0.42/0.79 |
| 解析サブステップ 1（4-3b） | 0.023 | 0.014/0.024/0.030 |
| 解析サブステップ 2（4-3b） | 0.011 | 0.013/0.007/0.013 |

自由窓（L=200、test、1,529 本）の終端速度誤差 [rad/s、J1/J2/J3]: persist 0.91/0.94/1.39、4-2 の A 0.27/0.41/0.75、**r6 0.089/0.051/0.087**、解析サブステップ 1 0.00016/0.00025/0.00031。L=50（6,370 本）は `reports/issue-42/a_tables.md`。図は `reports/issue-42/a_progress.png`。

## 考察
1. **改善の主因は学習データから接触を除いたこと**（7.2〜7.7 → 1.27、約 6 倍）。出力表現の変更だけ（r1）や標準化の違い（r0）では変わらない。4-2 の A は、接触行（σ が 100〜1e4 倍）に標準化と損失を支配され、非接触の精度が出ていなかった。
2. 幅・深さ・エポックの拡大で 1.27 → 0.72 とさらに改善したが、効果は逓減している（r3 → r6 の 3 倍の学習で 0.86 → 0.72）。weight decay は効かない（r5）。
3. 最良の r6 でも、解析サブステップ 1 の約 31 倍、サブステップ 2 の約 65 倍の誤差が残る。窓の終端では、4-2 の A の 3〜9 倍良く、persist の約 10〜16 倍良いが、解析の数百倍悪い。
4. 学習損失（非接触の標準偏差の約 1.3%）と val の差が残り、過学習と学習不足が併存している。ここから先は、データの追加（接触なしの走査を増やす）か、構造を入れた設計が必要になる見込み（未検証）。

## 留意点
- シード 0 の 1 本ずつ（再現性のばらつきは未評価）。r7（幅 1024・深さ 3、40 エポック）は計算時間が長く（約 5 分/エポック）、25 エポック時点で val 0.87 と r6 に及ばないため中止した。
- test は選択に使っていないが、全実験の結果を表に載せている。
- 非接触の判定は at_limit のみ。リミット近傍の（接触に入る前の）遷移も非接触に含む。
- 速度の観点: r6 は幅 512・深さ 4 で A（4-3b）より重い。4-3c の速度比較（幅 256・深さ 3）の数値は、そのままは使えない。

## 結論
接触を学習から除くと、NN A の自由運動精度は約 10 倍改善した（7.2 → 0.72 rad/s²）が、解析サブステップ 1（0.023）には約 31 倍届かない。現状の改善手段では、「解析並みの精度で、解析より 2〜5 倍速い NN」は得られていない。NN A の優位が残る範囲は、窓の終端で persist の約 10 倍良い精度で十分な用途に限られる。
