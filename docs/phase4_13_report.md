# Phase 4-13: モータ側状態を含む NN（A_el）の学習と弾性真値での評価（#73）

#71 で、剛体モデル（解析・A_pl）は弾性真値に対してゲイン最適化に使えないと分かった。本フェーズでは、モータ側の状態 (qm, dqm) を状態に含めた NN（A_el）が弾性真値を再現できるかを調べた。

## 1. 実施内容

| 項目 | 内容 |
|---|---|
| 設計 | 実機ではモータエンコーダで qm, dqm が測れ、PD もそれを使う。よって隠れ状態でなく観測できる状態 (q, dq, qm, dqm) を持つ。入力 [sin q, cos q, dq, θ=qm−q, dqm, τ, payload]、出力は 4 状態の 1 ms 後の加速度表現 |
| パイプライン | 励振モデル・シナリオ実行・間引き・組み立て・HDF5（`Xm`, `Ym`）・Python Dataset を弾性対応に拡張。`genSaDataset` に `opts.elastic` |
| データ | 弾性真値（f=20 Hz 相当の仮の剛性、#71 と同じ）。**縮小版**: 406 本・179 万遷移（全量 508 本の生成は 1 本あたり 400–900 秒かかり 10 時間以上のため、励振・保持・PTP のうち作成済みの 216 本＋パルス 180 本で打ち切り） |
| 行の選別 | 励振（チリープ・パルス）は共振を叩いて θ が最大 0.7 rad（閉ループの保持では p99 0.005 rad）に達する。実運転の範囲外なので、全軸 |θ| < 0.06 rad の行（train の 67%）だけで学習・選択 |
| A_el | 幅 512・深さ 4・AdamW wd 0.2・30 エポック（約 50 分）、seed 0。val の標準化 MSE 0.106 |
| 評価 | #71 と同じ 360 ケース（弾性真値）の閉ループステップ。PD はモータ側 (qm, dqm) でフィードバック（`closed_loop_el`）。dqm は 8 kHz の qm の数値微分 |

## 2. 結果（弾性真値に対する誤差、全 360 ケース）

| モデル | ステップ位置誤差 最大 [deg] | ΔOS 最大 [pt] | Δ整定 最大 [ms] | 最適ゲイン一致 |
|---|---|---|---|---|
| 解析（ペイロード反映） | 1.40 | 51.9 | 341 | 0/5 |
| A_pl | 1.40 | 51.8 | 345 | 0/5 |
| A_el | 21.1 | 731.7 | 1021 | 2/5 |

中央値（ステップ位置誤差 / ΔOS / Δ整定）: A_el 0.45° / 2.7 pt / 203 ms、A_pl 0.23° / 0.0 pt / 58 ms。

- A_el は軸 1・2 の ΔOS 中央値で A_pl と同程度（軸 1: 4.0 vs 11.8 pt、軸 2: 2.6 vs 5.8）。しかし手首（軸 3–5）の一部で閉ループが発散気味になり（ΔOS 最大 521–731%、位置誤差 最大 21°）、**最大値では剛体モデルより悪い**。
- 最適ゲインは 2/5 一致するが、残りは wn 30 など端の選択で、信頼できる一致ではない。
- 水準 G は満たさない。

## 3. 原因の見立て（1 ステップ誤差）

val の自由運動（|θ|<0.06）で、加速度 RMSE を目標の RMS で割った相対誤差:

| 出力 | 相対誤差 |
|---|---|
| モータ側の加速度（位置・速度） | 4–8% |
| リンク側の加速度（位置・速度） | 14–58%（軸 1: 約 50%、軸 4・5: 23–58%） |

- モータ側は十分に合うが、リンク側は合っていない。リンク側の加速度はばねトルク k·θ（k ≈ 1e3–2e4 N·m/rad）が支配的で、θ の小さな誤差が大きく効く。この感度が MLP で難しい。
- 閉ループでは誤差が 1800 ステップ積もり、手首の高い固有振動数（57–86 Hz、ω·dt ≈ 0.4–0.5）で不安定化しやすい。

## 4. 解釈

1. モータ側の状態を入れるだけの素朴な NN 拡張では、弾性真値のゲイン最適化に必要な精度に届かない。設計（観測できる 4 状態を使う）自体は正しいが、学習の仕方に課題が残る。
2. 剛体モデルより良いと言えるのは軸 1・2 の中央値のみ。最大値・安定性では悪化しており、「弾性を扱えた」とは言えない。
3. データは縮小版（全量の約 57%、励振の共振帯が多く、実運転の θ 範囲の行が少ない）。データ不足の影響は切り分けられていない。

## 5. 制約・注意

- 弾性の剛性・減衰は #71 と同じ仮の代表値。
- 生成は未コミットの作業ツリー（`genClean=false`）。`validateSaData` は剛体の解析との照合なので弾性データには行っていない。
- 評価の dqm は数値微分（`truth_dqm` は書き出していない）。

## 6. 次の候補（判断が必要）

- 構造を与える: ばねトルク項 (kθ + cθ̇) を明示した 2 慣性の解析モデルを基準に、NN は残差だけ学習（B 型）。リンク側加速度の感度問題を避けられる見込み。
- データ: 閉ループ（保持・PTP・ステップ）に近い θ の小さい領域を増やす。励振の共振帯は絞る。全量 508 本の生成を続ける案もある。
- 学習: θ・(dqm−dq) を高精度な入力特徴にする、リンク側出力に θ への線形スキップ項を設ける、倍精度で書き出す、ロールアウト（複数ステップ）損失を使う。
