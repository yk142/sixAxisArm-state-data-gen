# Phase 4-14: A_el への入力ノイズ学習（issue #75）

## 目的
別プロジェクト j2-nss-8khz（#46, #51）では、学習時の入力ノイズで自己回帰の破綻が解消した。同じ手法で、#73 の A_el の閉ループ発散（手首）が減るかを確かめる。

## 実装
`python/train_a_el.py --noise-r r`: 入力状態 (q, dq, θ=qm−q, dqm) にガウスノイズ。σ = r × 各状態の 1 ステップ増分（Δq, Δdq, Δθ, Δdqm）の軸ごとの標準偏差。目標は真の状態に対する値（デノイズ型）。q は sin/cos を回転して反映。データ・構造・設定（幅 512・深さ 4・30 エポック・θ<0.06 フィルタ）は #73 と同一。r = 1, 3, 10, 30（seed 0）。

σ（軸平均）: r=1 で q 1.4 mrad、dq 0.15 rad/s、θ 2.4 mrad、dqm 0.09 rad/s。

## 考察（仮説。切り分けていない）
- j2 のノイズは「直前の加速度」入力で、これは前の値をコピーする近道を塞ぐ役割だった。A_el にその近道はなく、ノイズは状態そのものに入る。
- θ にノイズを入れると、入力 θ から出力（ばねトルク kθ に比例）への感度がならされる（ノイズ入り入力→真の目標の回帰は感度を弱める）。θ は 1 ステップ増分の 1 倍（2.4 mrad）でも閉ループ θ の p99（5 mrad）に近く、信号を壊している。モータ側の 1 ステップ誤差が 3 倍（0.05→0.16）に悪化したことと整合する。
- したがって、j2 の効果は状態の acc 入力に特有で、状態にそのまま適用するのは不適と考えられる。

## 限界
- r は 1 以上のみ（より小さい r、θ を除く軸だけのノイズは未試験）。seed 0 のみ。縮小データ。

## 次の候補

3. 刻みの細分化（手首 ω·dt が 0.4〜0.5）、データ増。
