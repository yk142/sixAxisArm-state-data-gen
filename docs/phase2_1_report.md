## 設計
- 既定の安全帯: 位置は可動域の 0.85、速度は最大速度の 0.60（J2 版と同じ）
- ゲイン: `Kp = Mmean·wn²`（wn = 60 rad/s）、`Kd = max(2·Mmean·wn, tauPeak/(0.2·qdMax))`
- 飽和: 軸ごとの瞬時最大トルク（定格の 3 倍）
- Dead Zone は帯の内側で厳密に 0 を返すため、帯の内側では励振を歪めない

## 見つかったこと
1. **Kd を J2 版の式（2·M·wn）のままにすると、速度が最大速度を超えた。** 飽和する強い励振で、J1 5.8 rad/s（上限 5.13）、J3 7.9 rad/s（上限 6.28）。J3 は慣性が小さく（Mmean 0.93）tauPeak が大きいため、臨界減衰のゲインでは止めきれない。
   - 第 2 項 `tauPeak/(0.2·qdMax)` を足し、速度が安全帯の上限を最大速度の 20% 超えたところで飽和に達するようにした。結果: 2 シードとも \|dq\| は最大速度の 0.78〜0.85 倍（J1 4.1、J2 4.26、J3 5.36 rad/s など）に収まった。
   - 位置は、飽和する強い励振でも安全帯（0.85）の縁付近で止まった（J2 の上端 0.843 rad の帯に対し最大 0.851 rad）。
2. **質量行列の対角は姿勢で大きく変わる**（J1: 1.68〜7.09、J2: 4.37〜6.09 kg·m²）。J3 は 3 軸では一定（0.93）。バリアのゲインは平均 `Mmean` で決めているため、慣性が小さい姿勢では減衰が強め、大きい姿勢では弱めになる。今回の試験では問題は出ていないが、姿勢ごとの調整はしていない。
3. **飽和する強い励振の実行時間は短い**: 2 s が 9〜12 s（実時間の 5〜6 倍）。Phase 2-0 の弱い励振（3 軸で 15 倍）より速い。トルクが一定の区間が長く、ソルバが大きな刻みを取れるため（Phase 1 の保持・自由落下と同じ傾向）と推測している（未確認）。励振の種類で実行時間が大きく変わるため、規模の見積もりは励振ごとに取り直す必要がある。
