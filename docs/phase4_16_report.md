# Phase 4-16: 2 慣性解析モデルの励振・PTP・保持での評価（issue #79）

## 結論
2 慣性の解析モデル（#77。学習なし、パラメータは真値と同一）は、ステップ応答以外の信号でも弾性真値によく合う。
- **閉ループ（PTP 4 本・保持 6 本、全長 5〜24 s）: リンク角 q の誤差は最大 0.0025°**（A_el は 1.1〜2.2°）。ねじれ角 θ の誤差は 0.04 mrad 以下（真値の θ は 4〜12 mrad）。
- **励振（共振を叩く信号、θ が最大 0.68 rad）の開ループ再生: K=100 ステップで q 誤差 0.0002〜0.5°（A_el は 1〜125°）**。K=1000 ステップでは 0.02〜5.7°（A_el は 10〜1200°）。
- 大きな誤差が出るのは、大きく共振している信号（step、chirp、pulse_a3/a4）を開ループで長く再生した場合に限られる。リミット接触のシナリオは対象外（選んだ全シナリオで接触 0%）。

学習は使っていない（#77 参照）ので、これは「構造が正しければどこまで通用するか」の確認で、実機では k・c・Jm が未知なことが残る。

## 評価の方法
- データ: 学習用に生成済みの弾性真値のキャッシュ（`data/cache/fullel6_*.mat`）から 23 本を `tools/sa_export_eval_el.m` で書き出し（Simscape は再実行していない）。閉ループ 10 本（ptp_v20/40/60/80 の 001、hold_p1〜p6 の 001。制御器は wn=60、ζ=1）、励振 13 本（bln_normal/high/low、chirp、freefall、micro、step、pulse 軸 1〜6）。ペイロードは 0 kg。
- 閉ループ: `closed_loop_el(iters=1)`（#77）で全長を 1 kHz で進め、真値との q・θ の差を軸別に。A_el は同条件（反復 2、#73 のモデル）。
- 励振: 真値の印加トルク（ソフトバリア込み）を 1 ms の区間平均で再生し、真値の状態から K ステップ進める。開始点は 4 点（等間隔、t=0 を含む）。2 慣性解析と A_el を同条件で。
- 実装: `python/eval_scen_el.py`、集計 `python/summarize_scen.py`。

## 読み取り
1. **閉ループでは問題ない**: 追従制御がかかる通常運転（PTP・保持）では、q・θ とも真値とほぼ一致。A_el との差は 3 桁。
2. **共振を叩いても K=100 ステップ（0.1 s）までは通用**: θ が 0.7 rad に達する chirp・step でも q 誤差は 0.4° 以下。A_el は 73〜125°（発散）。
3. **K=1000（1 s）の開ループでは、大きく共振する信号で 2〜5.7° に伸びる**（step、chirp、pulse_a4）。フィードバックのない長い再生で、非線形な大振幅の位相ずれが累積するためと見ている（原因の切り分けは未実施。評価器では閉ループにすれば抑えられる）。
4. この評価では 2 慣性解析の**構造に不足は見えない**。残る誤差源は、(a) k・c・Jm・摩擦などのパラメータ誤差（ここでは真値と同一で見えない）、(b) リミット接触（対象外）、(c) 初期の過渡。

## 限界
- パラメータが真値と同一。実機相当の誤差（k や c が ±数十% ずれる）では、より大きな誤差が出るはず。**感度の確認が次の課題**。
- リミット接触（contact 系のシナリオ・near-limit 保持）は未評価。2 慣性解析にはリミットの接触モデルがない。
- ペイロード 0 kg のみ。励振・PTP・保持のシナリオは 1 本ずつ（ptp は速度 4 種）。
- 開始点は 4 点。励振の誤差は、最大を取っているため悲観側。

## 次の候補
1. **パラメータの感度**: k, c, Jm, 摩擦を ±10〜30% ずらした 2 慣性解析で同じ評価をし、真値との差を見る → 残差を学ぶ NN（B 型）や k・c 同定が要る誤差の大きさを決める。
2. 残差 NN（B 型）の学習。
3. リミット接触の扱い。
