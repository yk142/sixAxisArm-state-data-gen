# Phase 2 要件・設計（叩き台）— 励振・シナリオ・PTP ベンチマーク

状態: **方針は合意済み（2026-10-12、下記「決定」）。本数などの数字は 3 軸の実行時間の計測後に確定**。issue #9。決定済みの前提は [handover.md](handover.md) §5、[phase1_report.md](phase1_report.md)、[phase2_0_report.md](phase2_0_report.md)。「要件 → 計画 → 実装」の順で、合意後に実装する。

## 前提（決定済み）
- 真値: Simscape（armature あり）。ode15s（MaxStep 125 µs）、filterTc 1e-6、出力は 8 kHz 格子（`SpecifiedOutputTimes`）。入力は 8 kHz 格子の標本値（線形補間）
- 遷移 `(x_k, τ_k) → x_{k+1}` は 1 kHz。**τ_k は区間でプラントに実際に入った入力の台形平均**。状態は瞬時値の間引き
- 段階: 腕 3 軸（J1〜J3、手首は 0 rad で fixed）→ 6 軸
- 生成時間が約 1 日以上になることは許容

| 資産 | 内容 | 使い道 |
|---|---|---|
| `c8GainDesign` | 質量行列から PD ゲインを設計（Kp = M_ii·wn²、Kd = 2ζ·M_ii·wn） | PD 制御器。**注意**: 親資産の実測で wn≈336 に狭い不安定帯がある。親資産の既定は wn = 150 |

親資産の閉ループは 6 軸のみ。3 軸の段階では、関数（軌道・FF・ゲイン）を再利用し、モデルは本リポジトリで組む。

## J2 版の構成（参考）
励振 8 種（bln_normal / bln_high / bln_low / freefall / chirp / step / micro）、姿勢保持 7 姿勢、リミット近傍、PTP ベンチマーク（速度スケール 4 × 3）。計 338 本。J2 版の Phase 2 レポートの教訓:
- リミット近傍は開ループの押し付けでは取れない（重力で張り付いて動かない）。閉ループ保持で、リミットから 1.7〜3.2° の範囲を取った
- 自由落下もソフトバリア（可動域の 85%）で止まるため、**データセットはリミットに一度も接触しなかった**（機械ストッパの挙動は学習対象外）
- 1 シナリオごとに Simscape のコンパイルで 10〜15 s かかる（Fast Restart は Phase 3 で検討）

## 6 軸で変わる点
| 項目 | J2 | 3 軸／6 軸の案 |
|---|---|---|
| 初期状態 | Sobol 3 次元 | 軸ごとの範囲（バリア帯の内側、リミットから 2° 以上）× 速度範囲を Sobol で。6 軸は 12 次元 |
| 励振 | 1 軸 | **軸ごとに独立な BLN／chirp／step**（軸間の相関はまず 0）。相関のある励振は後続の検討 |
| バリア | 1 軸の位置・速度バリア＋トルク飽和 | **軸ごと**に同じ構造。トルク飽和は軸ごとの `tauPeak`。Phase 1 で、手首の開ループ駆動は非現実的な速度（J6 で 680 rad/s）になると分かったため必須 |
| 励振の振幅 | 定格トルクの比 | 軸ごとの定格トルク `tauRated` の比。手首は定格の 10% 程度から（Phase 1 のリミット試験と同じ）。慣性が小さい軸は速度バリアで止める |
| 姿勢保持 | 7 姿勢 | 代表姿勢（J2 と J3 の組み合わせ）。6 軸は手首の特異点（J5 = 0 付近）の近傍を別途含めるか検討 |
| 制御器 | PD＋解析 FF | PD＋RNEA FF（関節空間）。ゲインは `c8GainDesign` |
| PTP | 1 軸 | 関節空間のウェイポイント間を 5 次多項式。軸ごとの速度制限から区間時間を決める |
| リミット近傍 | J2 のみ | 軸ごと。閉ループ保持で、参照をリミットの 4° 内側に置き外乱で攻める |

## シナリオ規模の案（3 軸、叩き台）
J2 版の構成をそのまま 3 軸へ。**本数は未確定**。生成時間は、3 軸の ode15s での実時間倍率が未計測のため、先に計測して決める。

| 区分 | パターン | 備考 |
|---|---|---|
| 励振 | bln_normal / bln_high / bln_low / freefall / chirp / step / micro | 軸ごとに独立。バリア・飽和付き |
| 姿勢保持 | 代表姿勢 × 外乱 | 閉ループ（PD＋FF）。外乱は BLN |
| リミット近傍 | 軸ごと × 外乱 | 閉ループ保持 |
| ベンチマーク | PTP 速度スケール 4 段階 × 繰り返し | 閉ループ。split = `benchmark` |

split はシナリオ単位（train / val / test = 70 / 15 / 15、PTP は benchmark）、乱数シードはシナリオごとに固定。

## 決定（2026-10-12、ユーザー。推奨どおり）
1. **規模**: 先に 3 軸の実行時間（ode15s、励振・閉ループ）を計測してから決める。目安は **J2 版の約半分（150〜200 本、シミュレーション時間は約 1,400 s）に確定**（ユーザー、実測後）。被覆の裏付けが取れるまでは足さず、Phase 3 の被覆評価を見て追加する
2. **リミット接触**: まずソフトバリアで止め、機械ストッパの挙動は学習対象外にする。**接触シナリオは Phase 3 の追加枠**にする（バリアをリミットの外側へ移すだけで足せるよう、バリア位置を引数にしておく）。J2 版では動的接触が 0.36% で誤差の約 90% を占め、静止押し付けが 93.6% だった
3. **制御器**: PD＋RNEA FF（`c8GainDesign`、`c8FeedForward`）。計算トルク法は必要になったら足す
4. **軸間相関**: 励振は軸ごとに独立（相関 0）で始める。相関のある励振は、被覆を見てから検討

## 実行時間の計測（ode15s、filterTc 1e-6、8 kHz 格子出力）
開ループ励振 2 s（`spike/phase2_scenario*.m` の弱い励振。最大 |dq| 0.03〜0.21 rad/s）、ウォームアップ後の 1 回の計測:

| 軸数 | 滑らかな正弦和 | 1 ms 区間一定 |
|---|---|---|
| 3 | 29.2 s（14.6 倍） | 31.2 s（15.6 倍） |
| 6 | 61.8 s（30.9 倍） | 60.8 s（30.4 倍） |

- 実時間倍率は **3 軸で約 15 倍、6 軸で約 31 倍**。軸数にほぼ比例する。
- 見積もり（1 台直列、シミュレーション時間のみ）: J2 版と同じ 2,860 s のシミュレーションで、3 軸は約 12 時間、6 軸は約 25 時間。J2 版の約半分（約 1,400 s）なら 3 軸で約 6 時間。
- **含まれないもの**: シナリオごとの Simscape コンパイル（J2 版で 10〜15 s／本）、閉ループ（制御器）のオーバーヘッド、バリアが働く強い励振での刻みの細かさ。いずれも未計測で、実行時間はこれより長くなりうる。1 ケース・1 シードの計測。

## 実装の順序（案）
1. 3 軸の実行時間の計測（励振・閉ループ）と規模の決定
2. 励振モデル（軸ごとのバリア・飽和）、`saParams`（軸別の導出パラメータ）
3. 閉ループモデル（PD＋RNEA FF）、PTP 軌道（親資産の軌道関数を再利用）
4. シナリオ表（`saScenarioSet`）、1 シナリオの実行（`runSaScenario`）、Sobol 初期状態
5. 全シナリオ種別を 1 本ずつ実行するテスト（ゲート G2）
6. 3 軸 → 6 軸へ拡張（手首を可動に）
