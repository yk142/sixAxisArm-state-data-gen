# Phase 4-3e: 閉ループ評価（issue #45）

各モデルを閉ループのプラントとして使い、Simscape の閉ループ真値と比べた。

## 方法
- 制御器: τ = sat(τ_ff + τ_dist + Kp(q_ref−q) + Kd(dq_ref−dq))、Kp = Mmean·wn²、Kd = 2ζ·Mmean·wn（wn=60, ζ=1）、軸ごと ±tauPeak。Simscape 側と同一式を Python（1 kHz）へ移植した。
- 移植の要点: 参照項は区間の台形平均、状態項は区間中点の状態（前区間の平均加速度で外挿）で評価する。区間先頭値（ZOH）では Simscape の印加トルクと最大 6 N·m RMS ずれたが、中点評価では 0.12 N·m 以下（`python/tests/test_closedloop.py`）。
- 入力と真値: `src/data/saClosedInputs.m`（`runSaScenario` と同じ参照・外乱の再構成）→ `tools/sa_export_closed_eval.m` → `data/export/closed_eval3.h5`（git 管理外）。
- シナリオ: ベンチマーク PTP 12 本、near-limit 保持 14 本（学習に使っていない新規 `cl_nearlimit_*` 12 本 + test の 2 本）。
- モデル: 解析、hybrid（リミットで状態維持、それ以外は解析）、A（4-3d r6）、B（4-2, seed 0）、切替 B（d=0.5°）。
- 実行: `python/eval_closed.py --out data/eval/closed3 --compile`、集計 `python/summarize_closed.py`。

- 全モデル・全シナリオで発散なし。
- 解析は 0.0003° RMS（最大 0.002°）まで真値に一致する。これは制御器移植の誤差を含む下限。
- A(r6) は PTP で RMS 最大 0.035°、最大誤差 0.117°。B(4-2) は near-limit で RMS 最大 0.054°、最大誤差 0.139°。
- hybrid と切替 B は解析と同じ値。真値がリミットに触れず、切替の閾値（0.5°）の領域にも入らなかったため。
- 追従誤差（参照との差）は真値と同水準（PTP 0.0002°、near-limit 0.22°）。

## 制約（重要）
- **near-limit 保持はリミット接触の評価になっていない。** 真値の可動範囲端までの最小余裕は 1.0〜3.5°（0.1° 以内の接触は 0 %）。参照がリミットの内側（refMargin）に収められ、PD が端に届かないため。ここで分かるのは「リミットの手前 1° までは全モデルが閉ループで使える」ことまで。接触を含む閉ループ評価は未実施。
- 軌道の保存は PTP は先頭 1 本のみ（図の時間履歴は ptp_v20_001）。指標は全本で算出。
- 学習は 1 seed。near-limit の評価は 12 本の新規シナリオ + test 2 本で、件数は少ない。
- 解析の速度（4-3c）と合わせた実時間評価は未実施。
