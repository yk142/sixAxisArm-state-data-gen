# Phase 4-2 報告（途中経過）: 3 軸 NSM の学習と区分別 1 ステップ誤差（issue #35）

## 実施内容
- 3 軸 full（242 シナリオ、train 874,000 遷移）で 3 モデル × 3 シード = 9 本を学習（CPU、約 1 時間 50 分）。
  - A: 純 MLP（X_spec → Y_spec 標準化）。B: 解析モデル（RK4）＋ NN 残差（σ_all で標準化、最終層ゼロ初期化）。
  - C: B と同じ入力特徴・解析モデルで、自由ヘッド＋接触ヘッド（ゲート g = max_a sigmoid((0.5−d_a)/0.2)）の 2 ヘッド残差。損失は at_limit の有無で別々に標準化。
  - MLP 256×3 SiLU（接触ヘッド 128×2）、Adam lr 2e-3 → 1e-5（ウォームアップ 200 step＋コサイン）、バッチ 4096、40 epoch、val 損失最小のエポックを採用。test は最終評価のみ。
- 実装: `python/sa_nsm/{model,train_lib}.py`、`python/train.py`、`tools/sa_train_run.sh`、集計 `python/summarize_train.py`、テスト `python/tests/test_model.py`（全体 19 件合格）。

## 所見
1. C の自由運動は解析モデルと同水準（シード間ばらつき ~2e-4）。ただし解析モデルを**上回ってはいない**（学習による改善は未確認）。
2. **C の接触誤差は解析モデルの値と小数 3〜4 桁まで一致**（動的 65.9 / 101 / 233、静的 14.3 / 12.1 / 27.4）。接触ヘッドが残差を出していない（ゲート・損失・最適化のいずれかの不具合の疑い）。
3. A・B は自由運動で解析モデルの 400〜1000 倍の誤差。B はシード間のばらつきが大きい（静的接触 50 ± 52）。
4. 動的接触は、どのモデルも状態維持の基準線とほぼ同じ。静的接触は、どのモデルも状態維持（0.15〜0.18）に遠く及ばない。**基準線に対する改善倍率は主張できない**。
5. 接触を学習で改善できたモデルは無く、4-2 の目的は**未達**。

## 未解決・次の作業
- C の接触ヘッドが働かない原因の調査（ゲート値・接触ヘッド出力の大きさ・損失内訳。追加学習なしで確認できる範囲から）。
- 接触の基準線は「状態維持」のため、静的接触では状態維持を下回るモデルが無い。接触の予測を「状態維持＋残差」とする構造も検討対象。
- PTP は benchmark の自由運動に含まれる（区分別の PTP 表は、評価コードの groups に PTP 区分が無いため未掲載）。
