# Phase 4-2 報告（途中経過）: 3 軸 NSM の学習と区分別 1 ステップ誤差（issue #35）

## 実施内容
- 3 軸 full（242 シナリオ、train 874,000 遷移）で 3 モデル × 3 シード = 9 本を学習（CPU、約 1 時間 50 分）。
  - A: 純 MLP（X_spec → Y_spec 標準化）。B: 解析モデル（RK4）＋ NN 残差（σ_all で標準化、最終層ゼロ初期化）。
  - C: B と同じ入力特徴・解析モデルで、自由ヘッド＋接触ヘッド（ゲート g = max_a sigmoid((0.5−d_a)/0.2)）の 2 ヘッド残差。損失は at_limit の有無で別々に標準化。
  - MLP 256×3 SiLU（接触ヘッド 128×2）、Adam lr 2e-3 → 1e-5（ウォームアップ 200 step＋コサイン）、バッチ 4096、40 epoch、val 損失最小のエポックを採用。test は最終評価のみ。
- 実装: `python/sa_nsm/{model,train_lib}.py`、`python/train.py`、`tools/sa_train_run.sh`、集計 `python/summarize_train.py`、テスト `python/tests/test_model.py`（全体 19 件合格）。

## 所見
1. C の自由運動は解析モデルと同水準（シード間ばらつき ~2e-4）。ただし解析モデルを**上回ってはいない**（学習による改善は未確認）。
2. **C の接触誤差は解析モデルの値と小数 3〜4 桁まで一致**（動的 65.9 / 101 / 233、静的 14.3 / 12.1 / 27.4）。接触ヘッドが残差を出していない（ゲート・損失・最適化のいずれかの不具合の疑い）。
3. A・B は自由運動で解析モデルの 400〜1000 倍の誤差。B はシード間のばらつきが大きい（静的接触 50 ± 52）。
4. 動的接触は、どのモデルも状態維持の基準線とほぼ同じ。静的接触は、どのモデルも状態維持（0.15〜0.18）に遠く及ばない。**基準線に対する改善倍率は主張できない**。
5. 接触を学習で改善できたモデルは無く、4-2 の目的は**未達**。

## 原因調査と C の改良試行（シード 0 のみ、追加の 3 シード評価はしていない）
### 調査で分かったこと
- 9 本とも、train 損失は下がり続けるが val 損失は 2〜10 エポックで最小になった後に悪化する（過学習）。val 最小のエポックを採用したため、**ほぼ学習初期のモデルが選ばれた**。これが「C の接触誤差が解析モデルと小数 3〜4 桁まで一致」の直接の原因。
- C のゲートは正常（接触遷移で平均 0.93、自由運動で 0.004）。接触ヘッドは単独学習なら学習できる（接触の標準化 val 誤差 0.895 → 約 0.52）。
- 混合学習では、非接触の遷移もゲート（>0）経由で接触ヘッドに勾配を流し、σ_contact/σ_free（100〜10⁴）倍に拡大されて接触の学習信号を埋もれさせる。
- リミット手前 0.5° 以内の遷移は、接触（at_limit は開始か終了が 0.1° 以内）に入るかが開始状態だけでは決まらない。σ_free で測ると、接触ヘッドのわずかな出力に 10⁷ 倍の罰則が掛かって発散する。

### 試行（C、シード 0、test の加速度換算 RMSE [rad/s²]、J1/J2/J3）
| 版 | 変更 | 結果 |
|---|---|---|
| v2 | 学習率 3e-4、AdamW、接触ヘッド 64 幅、ヘッド別のチェックポイント | 過学習は解消。接触ヘッドは学習されず（接触の val 損失 0.801 = 解析モデル相当） |
| v3 | 非接触の遷移で接触ヘッドを勾配から切り離し | 発散（出力値が残るため） |
| v4/v5 | 非接触の遷移で接触項を外す（v5 は補助項も追加） | train は健全、val が 10⁵ 台に爆発（リミット近傍の非接触遷移） |
| v6 | 損失の区分を「接触ゾーン = at_limit またはゲート > 0.01」に変更（ゾーン内は σ_contact） | 静的接触 6.0 / 7.3 / 9.8、動的接触 64 / 94 / 224。ゾーン外は解析モデルと同水準だが、ゾーン内の非接触（1.4%）に誤差が漏れ、自由運動全体は 0.51 / 1.07 / 1.88 |
| v7 | v6 のゾーン内の非接触を幾何平均 √(σ_free·σ_contact) で標準化 | 漏れは J1/J2 で減（1.5 / 2.1）、J3 は残る（14）。静的接触は 13.1 / 9.8 / 22.2 に後退。自由運動全体 0.19 / 0.27 / 1.78 |

ゾーン外（全体の約 99%）は v6・v7 とも解析モデルと同水準（0.0101〜0.0102 / 0.0063〜0.0065 / 0.0121〜0.0124）。接触遷移（at_limit）では解析モデルより 2〜8% 小さい誤差（動的）、静的接触は 14 → 6〜13。ただし**状態維持の基準線（静的 0.145 / 0.173 / 0.177）には遠く及ばず**、動的接触もほぼ同水準で、改善倍率は主張できない。

## 結論と次の作業
- 学習モデルは、自由運動で解析モデルを上回れず、接触で状態維持を上回れなかった。接触の学習と自由運動の精度は、遷移が接触に入るかを開始状態だけでは決められないことから、尺度の調整だけでは両立できなかった。
- **方針（ユーザー決定）**: 接触の予測は学習で解決せず、解析モデル（自由運動）＋状態維持（接触）を基準として、**4-3 の閉ループ評価で「学習モデルが解析モデルに勝つ場面があるか」を先に確かめる**。リミット到達時の扱いは 4-3 で決める。
- 未解決: 接触の分類+回帰への分割（実装約半日）は保留。A・B の過学習対策（正則化）、改良版 C の 3 シード評価は行っていない。
- 本ブランチのコード（C の `train_loss`・ゾーン・ヘッド別チェックポイント、`train.py` の `--lr --wd --width-c --tag`）は v6/v7 の検証用で、本番 9 本の学習（`data/models/full3`）は改良前のコードで実行した。
