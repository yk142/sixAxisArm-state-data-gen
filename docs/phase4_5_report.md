# Phase 4-5: 6 軸の閉ループ評価（PTP とリミット近傍保持、接触なし）(#55)

## 目的
Phase 4-4（#53）は 6 軸を短い窓（開ループ）までで評価した。4-3e（3 軸）と同じ手順で、6 軸の閉ループ（PD + RNEA FF の制御器 + モデルをプラント）を評価する。

## 方法
- 真値: Simscape の 6 軸閉ループ。PTP はベンチマーク 12 本（キャッシュの真値）、保持（nearlimit）は test の既存 4 本＋新規 24 本（シード = seedBase + 175000 + i、Simscape を新規実行）。計 40 本。接触は評価しない。
- 制御器の Python 移植は 6 軸でも成立する（`python/tests/test_closedloop.py` を 3 軸・6 軸で実行。実印加トルクとの差 < 0.2 N·m）。
- モデル（5 種）: 解析 RK4、hybrid（リミット拘束中は状態維持）、A（4-4 の r6、seed 0）、B（4-4 の B_s0）、B 切替（d = 0.5°）。
- 指標: Simscape 閉ループとの位置・速度誤差、追従誤差、発散の有無。

## 結果（`reports/issue-55/summary.md`、`closed_loop.png`）
| 群 | モデル | 位置 RMS 最大 [°] | 位置 最大誤差 [°] | 速度 RMS 最大 [rad/s] | 発散 |
|---|---|---|---|---|---|
| PTP 12 本 | 解析 / hybrid / B 切替 | 0.0001 | 0.000 | 0.0001 | 0 |
| | B | 0.0008 | 0.002 | 0.0005 | 0 |
| | A | 0.129 | 0.370 | 0.0080 | 0 |
| nearlimit 28 本 | 解析 / hybrid / B 切替 | 0.0018 | 0.006 | 0.0011 | 0 |
| | B | 0.0027 | 0.007 | 0.0009 | 0 |
| | A | 0.0104 | 0.033 | 0.0052 | 0 |

- 全モデル・全 40 本で発散なし（有限・|q| < 10 rad）。
- 解析は閉ループでも Simscape とほぼ一致（PTP 位置 RMS 最大 0.0001°、保持 0.0018°）。誤差が最大なのは手首（J4〜J6）。
- B は解析とほぼ同じ。3 軸の 4-3g で見た J2 の逸脱（接触データの混入が原因とみられる）は 6 軸では出ない。6 軸データには接触行がないためで、「B が接触に強い」という意味ではない。B 切替（接触付近の切替）は、接触を学習していない 6 軸の B では解析と一致し、意味を持たない。
- A は PTP で位置 RMS 最大 0.129°（軸別最大: J1〜J6 = 0.047 / 0.033 / 0.052 / 0.069 / 0.129 / 0.128）。保持では最大 0.0104°（J6）。3 軸の A（0.035° / 0.0023°）より大きいが、シナリオ・軸数が違うので倍率としては比べない。誤差が大きいのは手首軸と高速 PTP（v60・v80）。
- 追従誤差（参照との差）は真値自体が保持で最大 1.25°（J6）あり、どのモデルもそれと同じになる（飽和・外乱による）。モデル間の差は 0.001° 程度で、追従指標ではモデルを区別できない。

## 留意点
- 解析は真値の生成モデルと同じ式なので、解析と真値の一致はほぼ自明（実機とのずれは見ていない）。
- 6 軸の B・A は 1 seed。A は 6 軸向けに未調整（3 軸の設定のまま）。
- 接触・リミット押し付けは 6 軸データがなく、評価していない。保持 nearlimit も押し付け（pushDepth）ではなく、リミットの 4° 内側での保持。
- 時間: 解析・B は 12 PTP で約 880 s、A は 33 s（A の 1 ステップ速度が約 25 倍速いのは、この評価の実装での値で、4-4 のバッチ 1 の速度比とは別）。
